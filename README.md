# Živý zámek Toužim – nový web (náhled)

Testovací verze nového webu spolku Živý zámek Toužim, z. s.
Ostrý web běží na hostingu Webglobe; sem se ukládají verze a testovací náhled (GitHub Pages).

- `index.html` – celý web (jedna stránka, sekce přes #odkazy)
- `img/` – fotky a grafika
- `docs/` – dokumenty ke stažení (stanovy, členský řád, přihláška)
